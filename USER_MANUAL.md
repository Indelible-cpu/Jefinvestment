# User Manual - Jef Investment ERP

## Logging In
1. Navigate to the ERP web address.
2. Enter your username and password.
3. If you have multiple branch access, ensure you are logged into the correct branch.

## Dashboard
The dashboard displays your daily snapshot:
- **Today's Sales:** Total revenue processed today.
- **Pending Syncs:** Number of transactions waiting to upload. A red number means you are currently offline.

## Point of Sale (POS)
1. **Adding Items:** Tap any product, stationery, or service to add it to the cart.
2. **Quantities:** Use the `+` or `-` buttons next to cart items.
3. **Discounts:** Tap the item discount or apply a global discount before paying.
4. **Payment:** Select Cash, Bank Transfer, etc., and tap **Pay Now**.
5. **Receipts:** A receipt window will pop up and attempt to print automatically.

## Offline Mode
If internet goes down, **keep using the POS**. You will see the "Pending Syncs" number on the Dashboard go up. DO NOT close the browser window. Once the internet returns, the system will automatically upload all pending sales in the background.

## Stationery & Tech Services
These function exactly like products but do not deduct from physical inventory. They simply log as service revenue.
